How it works

01 · Submit

Hono validates the input, hashes the normalized content, writes a queued row in D1 and pushes a small message to Cloudflare Queues. The client gets a 202 instantly.

02 · Process

The consumer claims the job, fetches the URL safely (DNS-over-HTTPS, private-IP blocking, redirect re-checks), and cleans the text.

03 · Cache or call

A KV lookup by content hash can skip the model entirely. On a miss, a free OpenRouter model returns schema-validated JSON with a repair retry.

04 · Persist

The result and token usage land in D1, the job becomes completed, and an HMAC-signed callback is delivered if one was requested.
